# v3.2.0: two new rules, a CI severity flag, and fewer misses

Dr. Unslopovich now knows 33 rules, reads more color formats and file types, and lets you pick which severity fails the scan.

## Added

- `reduced-motion` rule: flags animations with no `prefers-reduced-motion` fallback (#104 by @anhnt256).
- Flag inputs that use a placeholder as their only label (#105 by @anhnt256).
- `--fail-on` chooses which severity fails the scan (#100 by @anhnt256).
- `--list-rules` shows each rule's stacks and platforms (#59 by @anhnt256).
- Fixtures for Vue, Svelte, Astro and Ionic (#106 by @anhnt256), UIKit (#101 by @anhnt256), Android XML (#22 by @anhnt256), and the native gradient-text and glow-shadow branches (#103 by @anhnt256).
- Tests for the tracked-caps-label SwiftUI branch (#58 by @anhnt256) and the installer's `--help`, `--agent` and `--project` flags (#57 by @anhnt256).

## Fixed

### Scan and CLI

- The scan fails when it read zero files (#99 by @anhnt256).
- Invalid detector config files are reported (#134 by @cloudgpuapp).
- Less stylesheets are scanned as CSS (#132 by @ghozali25).
- A bad `--platform` value is named instead of printing usage (#54 by @anhnt256).
- A concise error when `--ignore` is missing a value (#119 by @Papito084).
- A JSX comment on the line above silences the next line (#95 by @gasparoff).
- The installer refuses to install into the skill's own folder (#93 by @gasparoff).

### Colors

- `#RRGGBBAA`, `#RGB` and `#RGBA` hex colors are read (#61 by @anhnt256).
- `#AARRGGBB` colors are read in slop-gradient (#23 by @tridev-tej).
- `0xRRGGBB` colors are read alongside `0xFFRRGGBB` (#62 by @anhnt256).
- slop-gradient reads only a gradient's own colors (#83 by @Dszae).
- template-theme accepts a `#FF` alpha prefix (#86 by @anhnt256) and catches Expo starter leftovers (#102 by @anhnt256).

### Rules

- glow-shadow: Tailwind colored and arbitrary glow shadows (#36 by @techkayacodes), Android `shadowColor` on one line or with alpha (#63 by @anhnt256), `#0000ff` and a saturated second color in shadow lists (#85 by @anhnt256). Inset accent bars with no blur are skipped.
- gradient-text: a gradient brush is flagged only inside text styles (#94 by @anhnt256).
- hover-scale: Tailwind arbitrary scale values (#53 by @anhnt256) and standalone CSS `scale` (#118 by @Prapathomsit).
- transition-all: `all` anywhere in a transition list (#46 by @anhnt256), stopping at the quote that ends a CSS-in-JS value (#49 by @Dszae).
- img-no-alt: Next.js `<Image>` without alt (#81 by @anhnt256), Angular `[alt]` bindings and Svelte `{alt}` shorthand (#97 by @anhnt256), bare `alt` attributes in web templates (#130 by @Nandaninaulaa).
- clickable-div: href-less anchors with `onClick` are flagged (#90 by @anhnt256), and the exemption needs both an interactive role and `tabIndex` (#123 by @Papito084).
- unverified-claim: an adjective after the number (#38 by @anhnt256) and "Join ... businesses" (#87 by @anhnt256).
- welcome-back: greetings with or without `!` (#30 by @anhnt256), and a name is required after the comma (#52 by @anhnt256).
- oops-error: log calls and thrown errors are no longer flagged (#98 by @anhnt256), and "Whoops" is (#131 by @ghozali25).
- Sparkle icons: `<Sparkle />`, `<SparkleIcon />` and `<WandSparkles />` (#84 by @anhnt256), and sparkle-derived SF Symbols (#110 by @ayushnandi718-dev).
- reduced-motion recognizes JS reduced-motion guards (#124 by @Papito084).
- tracked-caps-label detects leading-dot tracking and rem letter-spacing (#120 by @Papito084).
- drawer-nav matches the pre-SF3 `line.horizontal.3` symbol (#122 by @Papito084).
- vague buttons are caught in Swift, Kotlin and Dart (#56 by @anhnt256).
- safe-area-off flags `.ignoresSafeArea(.all)` (#55 by @anhnt256).
- focus-removed flags bare `focus:outline-none` (#91 by @anhnt256).
- glass-everywhere counts Tailwind `backdrop-blur` classes (#89 by @anhnt256).
- nested-cards no longer flags Card subcomponents (#92 by @anhnt256).
